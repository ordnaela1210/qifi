# Trucking Management System

This is a minimal Flask application intended to demonstrate the basic structure of a trucking management system. It allows recording vehicles, maintenance records, spare parts purchases, inventory items, and tool usage.

## Requirements

* Python 3.8+
* Flask
* Flask-SQLAlchemy

Install requirements with:
```
pip install Flask Flask-SQLAlchemy
```

## Running the Application

```
python app.py
```
The application uses a local SQLite database (`app.db`) stored in the same directory.

This is only a starting point and can be extended to provide authentication, more complex workflows, and reporting.
